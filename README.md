## Overview  
Zarrin is a responsive, multi-page corporate blog website focused on artificial intelligence, emerging technologies, and the future of innovation. Built around the tagline “How AI Will Change the Future,” 
the website presents technology-related articles in a clean, business-oriented design that prioritizes clear content hierarchy, readability, and usability.

---

## Key Features & Achievements
- ✅ Responsive Design: Developed a flexible, mobile-first interface that adapts to different screen sizes and devices, providing a consistent user experience across desktop, tablet, and mobile.
- ✅ Animated SVG Preloader: Created an SVG logo-drawing animation that progressively reveals the brand mark during the page loading experience.  
- ✅ Spring-Powered Search: Implemented an interactive search component with an animated dropdown form, using spring physics with carefully tuned stiffness and damping values for a natural, responsive feel. 
- ✅ Interactive Contact Popup: Built a contact form popup with field validation to provide clear feedback and improve form usability.
- ✅ Physics-Based Boop Animations: Developed tactile microinteractions using JavaScript-triggered CSS classes and spring-inspired motion, giving selected interactive elements a playful, responsive feel. 
- ✅ Animated Mobile Navigation: Enhanced the mobile burger menu with custom SVG animations and spring-based motion.
- ✅ Subtle Entrance Animations: Used opacity and translate transitions to introduce page content smoothly while keeping the focus on the articles and their hierarchy.
- ✅ Interactive Hover States: Added clear hover feedback to buttons, navigation links, cards, and other interactive elements to make the interface intuitive and responsive.
- ✅ Reduced-Motion Support: Respecting prefers-reduced-motion, the more expressive animations are disabled or simplified for users who prefer reduced motion, with content remaining accessible.
- ✅ Accessibility: Focused on semantic structure, keyboard interaction, and screen-reader usability to support a more inclusive browsing experience.
- ✅ Performance Optimization: Kept the visual experience lightweight and focused on efficient loading and smooth interaction across devices.
